# CrewSync

🚀 A Full-Stack Smart Workforce Management & Analytics Platform

## 📌 Project Overview

CrewSync is an enterprise-level HR Management & Employee Analytics platform designed to manage employees, attendance, leave, payroll, and performance while providing powerful business insights through interactive dashboards.

---

## 🛠 Tech Stack

### Frontend
- React.js
- Tailwind CSS

### Backend
- Node.js
- Express.js

### Database
- PostgreSQL

### Analytics
- Python
- Pandas
- Power BI

## ✨ Features

- Employee Management
- Attendance Tracking

- Payroll Management
- Performance Monitoring
- HR Dashboard
